# 反设计 · Anti-Design

> 刻意打破网格、撞色与对齐规则，用“错误感”表达态度，常见于时尚与音乐领域。

## 1. 视觉特征

- 错位是设计出来的：每处偏移都要能解释（例如 7° 旋转呼应主题）。
- 撞色只在关键区块使用，其余保持黑白以保证信息可读。
- 字体混排（衬线 + 等宽 + 手写）制造冲突。
- 图像故意低质、裁切、过曝，模拟扫描件。

## 2. 适用与慎用

**适合：** 潮流品牌、音乐与展览海报、亚文化社区、限量发售页。

**慎用：** 工具型产品、政务与教育、需要清晰导航的任何界面。

## 5. 实施要点

1. 保留一个“稳定层”（导航 + 主 CTA），其余元素才允许破坏网格。
2. 用 CSS `transform: rotate()` 做 1°–4° 的微倾，不要超过 8°。
3. 混排字体最多三种，字号阶梯仍要清晰。
4. 移动端收敛破坏性，优先保证可点区域。

## 6. 常见反例

- 全页错位，用户无法判断点击目标。
- 用反设计掩盖糟糕的排版基本功。
- 导航也一起反设计，转化率直接归零。
